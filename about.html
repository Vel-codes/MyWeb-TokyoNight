What this is

Tokyo Night Theme is a curated collection of dark, neon-inspired color palettes designed for modern interfaces, code editors, and creative projects.

Inspiration

Inspired by Tokyo after sunset — glowing neon signs, rain-soaked streets, deep shadows, and soft highlights — these palettes focus on calm dark backgrounds with vibrant accent colors. The website is inspired by this website.

Who it's for
  • • Developers building apps, dashboards, and themes
  • • Designers working on dark UI and web projects
  • • Creators who love clean, aesthetic visuals
How to use

You can freely use these palettes in personal or commercial projects ofcourse. Copy HEX or RGB values directly from the palette and apply them in CSS, design tools, or editor themes.

About the creator

Built by a developer (velix) who enjoys dark UIs, clean design. This project is part of an ongoing journey of mine, journey of a software engineer.
